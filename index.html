Hinweis: Mitteilungen erreichen dich nur, solange die App geöffnet oder im Hintergrund ist. Die farbigen Hinweise oben in der App funktionieren immer.

☁ Cloud-Sync aus

Empfohlen. Deine Daten landen als eine JSON-Datei in einem privaten GitHub-Repo. Keine Größenbeschränkung, und jeder Speichervorgang wird ein Commit — du kannst also jeden früheren Stand zurückholen.

  1. Auf GitHub ein neues privates Repo anlegen, z.B. tracker-daten. Leer lassen genügt.
  2. github.com/settings/personal-access-tokens → Generate new token → Fine-grained. Unter Repository access nur dieses eine Repo wählen, unter Permissions → Repository permissions → Contents: Read and write. Laufzeit ruhig lang setzen, sonst musst du ihn erneuern.
  3. Token kopieren und hier einfügen — er bleibt auf diesem Gerät.

Der bisherige Weg. Kostenlos über jsonbin.io: dort registrieren → API Keys → Master Key kopieren und hier einfügen. Achtung: Der Gratistarif hört bei 100 KB auf — ein Jahr Nutzung wiegt rund 130 KB.

Ohne Passwort liegen deine Daten im Klartext beim Anbieter. Mit Passwort sieht der nur unlesbaren Text. Passwort vergessen heißt: Cloud-Daten sind verloren. Auf jedem Gerät dasselbe Passwort eintragen.

📈 Verlauf

Normalerweise wächst der Verlauf ab heute, einen Tag pro Tag. Du kannst ihn aber sofort aus echten historischen Tagesschlusskursen berechnen lassen – gerechnet mit deinen heutigen Stückzahlen.

✨ Eintragen per Text

Ohne Schlüssel erkennt die App nur, was in deiner Lebensmittelliste steht – das reicht für den Alltag. Mit einem Google-Schlüssel versteht sie auch alles andere und schätzt die Nährwerte. Kostenlos über aistudio.google.com → Get API key.

Nicht eingerichtet.

Der Schlüssel bleibt auf diesem Gerät und wird nicht mit der Cloud abgeglichen. Beim Nachfragen gehen dein Text und die Namen deiner Lebensmittel an Google.

🏃 Strava aus

Holt deine Läufe und Radfahrten von selbst herein — sie landen als Ausdauer-Einträge im Trainingsbereich. Krafttraining kommt nicht von Strava, das trägst du hier weiter mit Sätzen und Gewicht ein; sonst stünde alles doppelt in der Wochenwertung.

Dazwischen braucht es eine kleine Brücke, weil Strava ein Geheimnis verlangt, das nicht in dieses öffentliche Repo darf. Die Datei strava-worker.js enthält die Anleitung: Strava-Anwendung anlegen, Worker bei Cloudflare hochladen (kostenlos), Adresse hier eintragen.

Nicht eingerichtet.

Falls die Rückkehr in die App nicht klappt: Die Brücke zeigt am Ende einen Code an — den hier einfügen.

Der Zugang bleibt auf diesem Gerät und wird nicht mit der Cloud abgeglichen. Eine Webseite kann nicht im Hintergrund arbeiten: Neue Aktivitäten kommen beim nächsten Öffnen der App — mit dem richtigen Datum.
